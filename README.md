# Risk One v2

Entry、Stop Loss、枚数、目標RR、Take Profit価格を入力できます。

- RRを入力するとTP価格を自動計算
- TP価格を直接入力するとRRを自動計算
- 1枚あたりと合計の損失・利益を表示
- MGC / MNQ / MYM（US30系・Micro Dow先物）対応
- オフライン動作対応

公開時は全ファイルを同じ階層へアップロードしてください。

「表示銘柄を選択」でチェックした銘柄だけ表示できます。設定は自動保存され、最低1銘柄は表示されます。使用中の銘柄を非表示にすると、表示中の銘柄へ切り替わります。

入力モード：価格入力 / ポイント幅入力を切り替えられます。ポイント幅入力は損切り幅（pt）、枚数、利確幅（pt）またはRRで計算します。1ptは価格差1で、tick数とは異なります。入力は銘柄・モード別に保存します。
